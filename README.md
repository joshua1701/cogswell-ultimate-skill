# Cogswell Ultimate – Claude-Skill

Skill für Claude Code: autonome Website-Produktion mit Premium-Designstandard und Effizienzmodus (Modul 01–17, Skill-Router, Smart Context Engine, Tarife, Status-Texte).

- `cogswell-ultimate/SKILL.md` – Master-Skill (Einstieg)
- `cogswell-ultimate/reference/` – Router, Effizienz, Context Engine, Design-Bibliothek, Übergabe, Status-Texte, Tarife
- `cogswell-ultimate/modules/` – die 17 Spezialmodule

Installation in einem Projekt: Ordner `cogswell-ultimate` nach `.claude/skills/` kopieren (im Repo liegt unter `.claude/skills/` bereits eine Kopie, damit Claude Code den Skill in diesem Checkout direkt findet).

Die ausführende Plattform (Router, Token-Engine, Pipeline, Messungen) ist die Cogswell Studio Suite; der Skill ist dort die gemeinsame Quelle für Claude Code und die API-Prompts.
